# 수학 융합 수업 키트 (교실용)

https://j333333766-hub.github.io/math-insight-kit/

2026. 11. 14. 동부 「수학 수업 인사이드」 연수의 사례 나눔 두 가지(테셀레이션, 피타고라스 음률)를 학교 수업에서 그대로 쓰도록 만든 정적 사이트. 로그인·서버 없음.

- tess/ : 교사용 안내(2차시 흐름·발문·17가지 정답표·평가), student.html(학생 시작 화면, QR), sheet.html(인쇄 활동지)
- music/ : 같은 구성
- tools/ : 연수 사이트(algeo-dongbu-1114) 도구를 복사해 Firebase 연결을 뺀 것. vertex-master 는 찾은 조합을 localStorage(mik.vertexMaster)에, polypad-tess 는 미션별 그림판을 localStorage(mik.pp.mN)에 저장하고 [그림으로 저장]으로 PNG 내려받기.
- 폴리패드 API 키는 연수 사이트용으로 받은 키를 그대로 씀(github.io 에서도 동작 확인 11/13). 'Powered by Polypad' 가리지 않기.
