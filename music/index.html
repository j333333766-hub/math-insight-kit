피타고라스 음률

“아름답게 어울리는 소리에는 간단한 비가 숨어 있다.” — 현의 길이 비 1 : 2(완전8도), 2 : 3(완전5도)만으로 음계를 만들고, 완전5도를 12번 쌓은 (3/2)¹²이 7옥타브 2⁷과 딱 맞지 않는다는 사실(피타고라스 콤마)을 계산하고 귀로 확인하는 수업이에요.

대상·시간

중1 ~ 중3 · 2차시(45분 × 2). 음악과 협력 수업·자유학기 주제선택으로도 좋아요.

관련 내용

비와 비율 · 거듭제곱(중1) · 지수법칙·순환소수(중2) · 제곱근과 무리수(중3) · 계산기 활용

준비

학생 1인 1기기 + 이어폰(교실 소리가 섞이지 않게) · 교사 스피커 · 활동지 인쇄(선택)

학생에게 안내할 주소

수업 시간에 이 주소나 QR을 화면에 띄워 주세요. 학생 시작 화면에 ①~⑤ 도구가 순서대로 있어요.

학생이 쓰는 도구

① 완전5도, 완전8도 이해하기

건반 하나를 누르면 7반음 위·아래(완전5도), 12반음 위·아래(완전8도) 건반이 색으로 표시돼요(소리는 나지 않아요).

같은 활동을 3옥타브 건반으로 넓혀, 5도를 계속 쌓으면 어디까지 가는지 따라가요.

열기
③ 피타고라스 음률 계산기

주파수에 ×3/2, ×2/3, ×2, ×1/2, ×¹²√2 를 해서 음을 만들고, 결과를 주파수 칸에 끌어 놓아 소리를 들어요. [12평균율로 채우기]로 비교.

열기
④ 피타고라스 콤마 확인하기

(3/2)ⁿ 과 2ⁿ 거듭제곱 표, ×1.5·×2 계산기, 넓은 건반(A2~C10)으로 12번 쌓은 5도와 7옥타브가 어디에 닿는지 비교해요.

열기
⑤ 숫자로 연주하기

분수 a/b·π·e·√n 의 소수점 아래 숫자를 건반(1 도 ~ 7 시, 8·9·0 높은 도·레·미)으로 연주해요. 순환소수는 같은 가락이 되풀이돼요.

열기

1차시 · 간단한 비로 음 만들기

  1. 7분도입 — 대장간 이야기

    피타고라스가 대장간 망치 소리에서 어울리는 소리를 발견했다는 이야기, 줄(현)의 길이를 반으로 줄이면 한 옥타브 높은 소리가 난다는 사실을 소개해요. 고무줄·기타 줄이 있으면 직접 들려주세요.

    발문줄의 길이를 1/2로 하면 한 옥타브 위의 같은 ‘도’가 돼요. 그럼 2/3로 하면 어떤 소리가 날까요?

  2. 10분① 완전5도·완전8도 찾기

    건반을 눌러 기준음에서 완전5도(7반음), 완전8도(12반음) 떨어진 건반을 찾아봐요. 소리는 교사가 피아노 앱·악기로 들려주거나 ③ 계산기에서 들을 수 있어요. 길이 비와 주파수 비는 거꾸로(길이 2/3 ↔ 주파수 3/2)라는 것을 짚어요.

    발문기준음 ‘도’에서 완전5도 위는 무슨 음인가요? 그 음에서 다시 완전5도 위는요?

    ① 완전5도, 완전8도
  3. 8분② 3옥타브로 넓히기

    도 → 솔 → 레 → 라 → 미 → 시 … 로 5도를 계속 쌓으면 옥타브를 넘어가요. 넘어가면 ×1/2(한 옥타브 내리기)로 한 옥타브 안에 모아요.

    ② 3옥타브
  4. 17분③ 음률 계산기로 음계 완성

    ‘도’ 261.63Hz에서 ×3/2, 필요하면 ×1/2 을 하며 활동지의 표(도·레·미·파·솔·라·시)를 채우고, 주파수 칸에 끌어 놓아 들어 봐요. 파는 도에서 5도 아래(×2/3 → ×2)로 구해요.

    발문내가 만든 음계와 [12평균율로 채우기]의 음을 번갈아 들어 보세요. 어느 음이 가장 많이 다르게 들리나요? (미·시)

    ③ 음률 계산기
  5. 3분마무리

    음계의 모든 음이 (3/2)ⁿ 과 2ᵐ 의 곱으로 만들어진다는 것을 정리하고, “5도를 12번 쌓으면 다시 도로 돌아올까?”로 2차시를 예고해요.

2차시 · 피타고라스 콤마와 숫자의 노래

  1. 15분④ 5도 12번 vs 7옥타브

    5도를 12번 쌓으면 피아노 건반으로는 7옥타브 위의 ‘도’예요. 거듭제곱 표에서 (3/2)¹² 과 2⁷ 을 비교해요. 소리로도 확인하려면 ③ 계산기에서 261.63 × 1.01364 ≈ 265.2Hz 와 261.63Hz 를 차례로 들려주세요(아주 조금 높게 들려요).

    발문(3/2)¹² = 3¹² / 2¹² 이 2⁷ 과 같아질 수 있을까요? (3¹² 은 홀수, 2¹⁹ 는 짝수 → 절대 같을 수 없음)

    발문피아노는 이 문제를 어떻게 해결했을까요? (한 옥타브를 똑같이 12로 나눈 12평균율: 반음마다 ×¹²√2, 5도 = 2^(7/12) ≈ 1.4983)

    ④ 피타고라스 콤마
  2. 20분⑤ 숫자로 연주하기

    1/7, 1/4, 22/7, π, √2 를 차례로 연주해 봐요. 순환소수는 같은 가락이 되풀이되고, 유한소수는 곧 끝나고(뒤는 0), π·√2 같은 무리수는 되풀이 없이 이어져요.

    발문1/7 의 가락은 몇 음마다 되풀이되나요? 2/7, 3/7 은요? (모두 순환마디 6자리, 142857 을 돌려 놓은 것)

    발문22/7 과 π 는 처음 몇 음까지 같을까요? (3.14 까지 → 소수 둘째 자리까지)

    ⑤ 숫자로 연주하기
  3. 10분정리·성찰

    “완벽하게 맞는 음률은 없다 — 수학적으로 정확한 비(피타고라스 음률)와 어디서나 같은 간격(12평균율) 사이의 선택”을 정리하고, 활동지 생각 정리를 써요.

계산기로 구하면 끝자리가 조금 다를 수 있어요(반올림). 미(81/64)와 시(243/128)가 12평균율과 가장 많이 달라요.

피타고라스 콤마

(3/2)¹² = 531441/4096 ≈ 129.746, 2⁷ = 128 → 비 = 531441/524288 ≈ 1.01364 (약 1.4% 높음, 반음의 약 1/4)

3¹² 은 홀수이고 2¹⁹ 은 짝수이므로 3¹² / 2¹² = 2⁷ 은 불가능 → 완전5도를 아무리 쌓아도 정확히 옥타브로 돌아오지 않아요.

12평균율: 반음 = ¹²√2 ≈ 1.05946, 완전5도 = 2^(7/12) ≈ 1.49831 (3/2 = 1.5 보다 아주 조금 작음) → 12번 쌓으면 정확히 2⁷.

숫자로 연주하기 — 확인용 값
  • 1/7 = 0.142857 … 순환마디 6자리 · 2/7 = 0.285714 … · 1/3 = 0.3 … (한 음만 되풀이)
  • 1/4 = 0.25 (유한소수, 분모의 소인수가 2·5뿐) · 1/12 = 0.083 …
  • 22/7 = 3.142857 … 와 π = 3.14159 … → 소수 둘째 자리까지 같음
  • √2 = 1.41421356 … · √4 = 2 (자연수, 소수 부분이 모두 0)

평가 아이디어 (과정 중심)

무엇을어떻게 보나요
비로 음 만들기활동지 음계 표의 비와 주파수를 ×3/2, ×1/2 로 바르게 구했는가 · 만드는 과정을 거듭제곱으로 나타냈는가
추론(3/2)¹² ≠ 2⁷ 인 이유를 홀수·짝수(소인수) 로 설명했는가
연결순환소수·유한소수·무리수의 ‘가락’ 차이를 수의 성질과 연결해 설명했는가
성찰피타고라스 음률과 12평균율의 장단점을 자기 말로 비교했는가

수업 전에 알아 두면 좋아요

  • 브라우저는 화면을 한 번 누른 뒤에야 소리를 내요. 소리가 안 나면 건반을 한 번 더 누르고, 기기 음량·음소거를 확인하세요.
  • 30명이 동시에 소리를 내면 서로 들리지 않아요. 이어폰을 준비하거나, 짝 활동으로 한 기기만 소리를 켜게 하세요.
  • ③ 계산기에서는 결과값을 주파수 칸으로 끌어 놓기(드래그)해요. 태블릿에서 끌기가 어려우면 [입력칸으로] 단추를 쓰세요.
  • 음악 선생님과 함께라면: 실제 악기(기타·바이올린)로 순정률·평균율 차이를 들려주면 효과가 커요.
